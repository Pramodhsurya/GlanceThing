# GlanceThing — upcoming work

Notes from 24 September 2026. Names can change later.

## 1. Turn home features into apps, and let those apps offer layout widgets

Weather, calendar, AI usage, and the other home-screen features should become **their own apps**, the same way Music or Pomodoro already live in the swipe-down tray.

Each of those apps should also **ship widgets**. In the desktop Layout tab, you pick widgets **from an app** and drop them onto the normal Car Thing pages — not only as a fullscreen app, but as tiles on the home layout.

In other words:

- Open Weather / Calendar / AI usage (and the rest) from the apps tray, as full apps.
- From the same apps, add their widgets onto a page in the layout editor.
- The home pages stay the place you compose those widgets, instead of the features being hard-wired only as built-in frames.

Cover at least:

- Weather
- Calendar
- AI usage
- The other current home features that are not already tray apps (for example photo album / screensaver), so they follow the same “app + widgets” model

## 2. Car Thing as a real microphone device (if possible)

Expose the Car Thing’s microphone as its **own input device** on the computer.

When you are in a Teams (or similar) meeting and you open the list of microphones, the Car Thing should show up as an option you can switch to — the same way a headset or the built-in Mac mic does.

This is “if possible”: it depends on presenting the Car Thing capture as a system audio device on macOS / Windows.

## 3. Widgets for the existing tray apps

The apps that already live in the swipe-down tray should also **ship widgets**, so they can be added to the home pages in the Layout tab — not only opened as a fullscreen app.

That includes at least:

- Music
- Pomodoro
- Resource Usage
- Recording Notes
- GitHub
- Console Logs
- Link

Same idea as section 1: pick a widget from the app, drop it on a normal page.
